# Demo video script (T5)

30 seconds, screen recording of the live site with a voice-over. About 75 spoken words, so read it at a calm pace. No NASA logos, no NASA mission photos, no music with lyrics.

Live site: https://mehdi-abidi.github.io/flame-in-freefall/

## Shots

| Time | On screen | Voice-over |
|---|---|---|
| 0 to 5 s | Overview, top of the page. Hold on the headline. | "A lunar base will breathe about 30% oxygen. NASA's solid-material fire tests in orbit stopped at 22.2%." |
| 5 to 11 s | Scroll to the oxygen ruler, then the gap map. Hover one dot in the lunar box. | "We put every NASA PSI combustion test on one map, so the gap is easy to see." |
| 11 to 19 s | Rank page. Click Lunar base, then drag the Suppression slider up. Let the list re-order, then open the top row. | "Pick a habitat and what matters most. All 24 investigations re-rank live, and each one says why." |
| 19 to 26 s | Ask page. Click the example "Which diluent put out droplet flames at lower oxygen, CO2 or helium?" Wait for the answer, then hover a citation. | "Ask a question in plain English. Every answer cites the NASA record it came from." |
| 26 to 30 s | Back to the Overview headline, URL visible in the address bar. | "Flame in Freefall. Built on NASA PSI data for Space Apps 2026." |

## Before recording

1. Open the Ask page once and ask any question, then wait for the answer. The API sleeps when idle and the first answer can take up to a minute. After that, answers come in a few seconds.
2. Use paper (light) mode, browser zoom at 100%, window at 1920 x 1080, and close other tabs and notifications.
3. Pre-load the Rank page so the switch is instant.

## Recording on Windows

- Press Win + Alt + R to start and stop recording with the Xbox Game Bar. The file goes to Videos > Captures.
- Record the voice-over in the same take, or record the screen silently and add the voice in any editor (Clipchamp is built into Windows).
- Trim to 30 seconds. Export as MP4, 1080p.

## Upload

Upload to YouTube as Unlisted, or to Google Drive with "anyone with the link can view". Put the link in the submission form and in `submission-text.md`.
